# mentoria-pipeline-p2-2

Modelo do lab **P2.2** do domínio pipelines da mentoria StaffOps: a vitrine, com o Dockerfile
da trilha docker, e o workflow do P2.1, que publica no GHCR a imagem de cada commit da `main`
com a tag do SHA. Você o estende: uma tag de versão publica a versão, e um pull request
constrói sem publicar.

Faça **fork** deste repositório. O enunciado está no portal da mentoria, no lab P2.2.
